# Ananta store (MERN)
## Run
1. `cd server && cp .env.example .env` (set MONGO_URI and JWT_SECRET), then `npm i && npm run seed && npm run dev`  → API on :5000
2. `cd client && npm i && npm run dev` → site on :5173 (Vite proxies /api to :5000)
Demo checkout uses cash on delivery. Next: Razorpay (create order + webhook verify), admin panel, Cloudinary images.
